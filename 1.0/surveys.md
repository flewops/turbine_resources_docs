# Surveys

Customer feedback, assessments, certifications and live quizzes, with responses turned into CRM leads and interview forms for Recruitment.

## Survey types

### Choose a type

| Type | Use it for |
| --- | --- |
| Survey | Customer satisfaction, market research, event feedback |
| Live Session | Real-time quiz on a projector; participants answer on their phones |
| Assessment | Scored tests, certifications, training evaluations |
| Custom | Full control over every option |

## Building a survey

### Create a survey

1. Go to **Surveys → Surveys** and click **New**; choose the type.
2. Enter the title and an optional description or background image.
3. In **Questions**, click **Add a section**, then **Add a question**.
4. Pick a question type: multiple choice (one or several answers), single-line or multi-line text, numerical value, scale, date, date-time or matrix.
5. Add answer options; tick **Mandatory** where an answer is required.
6. For conditional logic, open the question's options and set **Conditional display** so it appears only after a chosen answer.
7. Click **Test** to try it yourself.

### Share and invite

- **Share** gives a public link and QR code for email, WhatsApp, your website or a printed job card.
- **Invite** sends personal links to chosen contacts so you can track who answered.
- Set **Access Mode** to anyone with the link or invited people only, and optionally require login.

## Scoring and certification

### Assessments

1. In the **Options** tab, set **Scoring** and mark correct answers and points on each question.
2. Set the **Required score (%)** to pass.
3. Tick **Is a Certification**, choose the certificate layout and email template, and optionally a badge and validity period.
4. Optionally limit attempts and set a time limit.

Passing a certification can be recorded on the employee's skills — useful for training compliance.

## Live sessions

### Run a live quiz

1. Create a survey of type **Live Session**.
2. Click **Create Live Session**; a session code and link are shown.
3. Participants open the link on their phones and enter the code.
4. Move question by question; results and the leaderboard appear on screen.

## Results

### Analyse responses

- **See results** shows charts per question; click an answer to filter all results by it.
- **Surveys → Participants** lists each response with score and status.
- **Detailed Answers** gives every answer line for export to Excel.

## Survey-to-lead

### Generate CRM leads

In the survey's options, tick **Generate Leads** and select the **Sales Team**. Each completed response creates a lead in [CRM](crm.md) with the participant's details and answers — useful for expo and event enquiries.

## Interview forms

### Use surveys in Recruitment

Attach a survey as the **Interview Form** on a job position. From an applicant, send it or fill it in during the interview; the result is stored on the applicant. See [Recruitment](recruitment.md#interview-forms).

## Administration

### Set-up

- Configure the outgoing mail server and test invitation delivery.
- Put the company logo and authorised signatory in company settings for certificates.
- Delete test responses before go-live; responses contain personal data.

### Access rights

| Role | Can do |
| --- | --- |
| Surveys User | Create and manage own surveys; see own results |
| Surveys Administrator | Manage all surveys and responses |
