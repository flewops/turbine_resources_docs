# Time Off

Leave requests, balances and allocations, multi-level approval, company holidays and the India sandwich rule.

## Requesting leave

### Submit a request

1. Open **Time Off → My Time → Requests** and click **New**.
2. Pick the time off type (for example Earned Leave, Sick Leave or Compensatory Off), the dates and, if allowed, half days.
3. Add a reason and save. The request goes to your approver.
4. Track it in **My Time → Days Off**. The **Overview** calendar shows who else is away.

Good to know:

- If you ask for more days than your balance, Turbine refuses with "does not have a valid allocation".
- **Sandwich rule** — a weekend or holiday between two leave days can be counted as leave, if HR has enabled it for that leave type.
- Company holidays and mandatory days are shown on the calendar.
- Approved leave is added to your timesheet automatically.

## Approving leave

### For managers and HR

1. Open **Time Off → Management → Time Off**; the default filter shows requests waiting for you.
2. Open a request, check the team calendar for overlaps, and click **Approve** or **Refuse** with a reason.
3. Types that need two approvals go to HR after the manager.

## Allocations

### Giving leave balances

- **Time Off → Management → Allocations → New** — allocate days to an employee, a department or a whole company.
- **Accrual plans** add days automatically over time — for example 1.5 days of earned leave per month.
- Employees can request extra allocation (such as compensatory off) where the leave type allows it.

## Administration

### Configure leave types

| Field | Purpose |
| --- | --- |
| Approval | No validation, manager, HR, or manager and HR |
| Requires allocation | Whether a balance is needed |
| Allow half day / hours | Partial-day requests |
| Sandwich rule | Count weekends and holidays between leave days |
| Public holidays and mandatory days | Company calendar by work location |

### Access rights

| Role | Can do |
| --- | --- |
| Employee | Request own leave and allocations |
| Time Off Officer | Approve team leave and allocate days |
| Time Off Administrator | Configure leave types, accruals and holidays |

## Troubleshooting

### Common issues

| Message or problem | Why | What to do |
| --- | --- | --- |
| "does not have a valid allocation" | Not enough balance | Ask HR for an allocation, or pick another leave type |
| Weekend counted as leave | Sandwich rule enabled for this type | Expected; check the policy with HR |
| Request not reaching the manager | No manager set on the employee | HR sets the manager |
