# Project

Plan, track and bill projects with task boards, milestones, dependencies, recurring tasks, timesheets and project profitability.

## Projects and tasks

### Navigate projects

**Project → Projects** shows each project as a card with open tasks and a status colour. Click a card to open its task board. **Tasks → My Tasks** lists everything assigned to you; **All Tasks** is available to managers.

### Create a task

1. Open a project and click **+** at the top of a stage (quick create), or **New** for the full form.
2. Set the **Title**, **Assignees**, **Deadline**, **Tags** and **Priority**.
3. Set **Allocated Time** and the **Milestone** if used.
4. Write the description; type "/" for checklists, tables and headings.
5. Break work down in the **Sub-tasks** tab.

### Move work forward

- Drag a card to the next stage — for example New → In Progress → Done.
- Use the status dot: **In Progress**, **Changes Requested**, **Approved**, **Done**, **Cancelled**.
- **Blocked By** — add predecessor tasks; the task shows as blocked until they are done.
- **Recurrent** — set a repeat (weekly, monthly) and the next task is created automatically.

## Milestones and status updates

### Milestones

Use the **Milestones** smart button on a project to create milestones with deadlines. Link tasks to them and mark a milestone **Reached** when complete. For milestone-billed services, reached milestones become invoiceable.

### Project updates

Post a status in the project's **Updates** — **On Track**, **At Risk**, **Off Track** or **On Hold** — with a progress summary. The colour shows on the project card.

## Timesheets

### Log time

- Open a task, go to the **Timesheets** tab and add a line: date, employee, description and hours.
- Or use **Timesheets → My Timesheets** to log the week in one grid.
- Allocated versus spent hours and progress update immediately.

## Billing and profitability

### Billing models

| Model | Service product setting | Invoice from |
| --- | --- | --- |
| Fixed price | Invoicing policy on ordered quantities; creates a project or task | Sales order |
| Milestones | Invoicing policy based on milestones | Reached milestones |
| Time and material | Invoicing policy based on timesheets | Approved timesheets |

Confirming a sales order with a service product creates the project or task automatically.

### Project profitability

The project's profitability panel adds up invoiced revenue, timesheet costs, purchases, vendor bills, expenses and materials consumed. **Project → Reporting** provides task analysis and customer ratings.

## Working with customers

### Portal and ratings

- Customers with portal access see shared projects and tasks, comment and upload files.
- Customers can submit tasks by email to the project's alias.
- When ratings are enabled, customers rate the service as tasks reach a rated stage.

## Personal to-do

### To-do list

The **To-do** application is your private task list. Create quick to-dos and convert them into project tasks when needed.

## Administration

### Project settings

| Feature | Where |
| --- | --- |
| Project stages | Project settings |
| Milestones, task dependencies, recurring tasks | Each project's **Settings** tab |
| Timesheets and billable | Each project's **Settings** tab |
| Customer ratings | Project settings and the stage's rating template |
| Visibility | Invited internal users, all internal users, or portal |
| Email alias | Create tasks from incoming emails |

### Templates and roles

Mark a project as a template with standard stages, milestones and tasks. Define **Project Roles** (for example Site Engineer, Designer, QA) on template tasks; when creating a project from the template, map each role to a person.

### Compliance calendar

A recurring-task project is a practical way to track statutory due dates — GST, TDS, PF, ESI and company-law filings — with an owner, due date and proof of filing attached to each task.

### Access rights

| Role | Can do |
| --- | --- |
| Project User | Work on tasks in visible projects |
| Project Administrator | Create projects, configure stages and settings |
| Timesheets User | Log own time |
| Timesheets Approver | Validate and edit others' time |
